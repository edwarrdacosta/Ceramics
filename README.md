# Ceramics

Self-contained single-file web apps — no build step, open the HTML directly or serve the folder.

- **Ceramic atelier** — [`index.html`](index.html): editorial atelier app with true-scale printing and joinery math.
- **LogicLab** — [`logic/index.html`](logic/index.html): an all-in-one tutor for propositional logic — a 10-lesson course from zero, a step-by-step symbolic solver that names the law used at every step, truth-table tools, and practice that diagnoses your specific misconceptions and tracks them over time. See [`logic/README.md`](logic/README.md).
